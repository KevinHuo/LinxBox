# LinX 应用

启用 Gateway 后，任务、历史和正文从服务连接读取，按目录／新回复通知刷新；按一次 OK 结束录音并发送。设计、容量与 TLS mock 验证见[Gateway 接入说明](../docs/gateway-client.md)。默认关闭该开关时保留下述演示与直接灵矽路径。

本轮以正式 Go Gateway 契约恢复灵矽 Agent 负责发送与回执的路径。此前 Node 演示服务和设备指定播报的测试、镜像及内存数字不作为本轮验收依据；真实服务地址稍后在本地配置。在线字库继续使用已确认清晰的 Noto Bold 16px、4bpp 平滑字形。

本目录实现 LinX 0.2 应用：`main.c` 为设备入口，`linx_ui.*` 绘制界面，`linx_demo.*` 与 `linx_content.*` 管理任务和示例内容，`linx_input.*`、`linx_navigation.*`、`linx_reader.*` 分别处理按键、导航和分页阅读。`linx_voice.h` 定义语音与手机配网命令和状态，`linx_protocol.*` 负责有界消息、设备接入与会话协议，其中 Hello、监听及打断规则从固定版本小智源码移植，来源和差异见 [`upstream.json`](../upstream.json)；`Kconfig.projbuild` 提供开关及 Wi-Fi 配置，`idf_component.yml` 固定解码器与现有 LVGL 版本。`linx_device.*` 管理联网与录放音，`linx_wifi_portal.*` 提供手机配网页；底层驱动通过 [hardware/](../hardware/folotoy/ai-passport/README.md) 接入固定上游 BSP，字体图片留在 [assets/](../README.md#资源与生成)。

## 操作与功能边界

- 上下键选择或翻页，短按 OK 进入或确认，默认长按 OK 约半秒返回；任务列表用返回手势打开设备设置。“返回方式”可切换长按／双击，异步保存成功后生效并在重启保留。长按模式短按松手立即确认；双击模式单击等待 300 ms 窗口，完整双击只返回一次。两种模式长按松手都不补发确认。
- 设备设置的“Wi-Fi 网络”打开手机配网，语音页提示先设置 Wi-Fi 时短按 OK 也可进入。设备显示临时热点和密码；手机连接后在 http://192.168.4.1 选择网络并输入密码，成功后自动保存并关闭热点。`linx_wifi.*` 只保留固定容量网络类型和密码格式检查；试连取得地址后才保存，失败可在网页重试，使用当前返回手势取消。
- 概览只有“阅读本轮回复”“继续沟通”“最近对话”。阅读页只翻页，单击 OK 不录音、不发送；使用返回手势回到概览后，选择“继续沟通”录入。首版移除图片与附件入口。
- 概览后台准备语音，麦克风保持关闭；选择录入后每次只处理一条指令，短按 OK 结束并发送。等待／播放时 OK 不开启新录音；完整反馈播完、音频休眠后返回概览。上下键不取消，返回手势直接退出本条并停止本地录放音。
- 未绑定时显示灵矽网关返回的真实六位激活码；在平台完成绑定后短按 OK 重试。连接、网络时间、协议或音频失败会显示状态，短按 OK 手动重试；不把上一轮录音自动重发。
- 未启用 Gateway 时，关闭 `CONFIG_LINX_VOICE_ENABLE` 后保留原模拟输入：八秒后或再按 OK 结束，再确认转写；离开确认页不会发送。
- 登录任务模拟运行八秒，支付任务等待回复，设计任务展示完整长回复。每个任务保留本次开机最近八轮，重启恢复初始示例。
- 演示选项可模拟离线或一次发送失败；未发送指令可恢复草稿后重试或取消。已接收指令离线时暂停，未收到的草稿需手动重试；每个任务只有一个待执行名额。

默认演示目录中的任务列表、回复正文、电量和离线模式转写为本地示例；真实模式的语音页直接连接灵矽智能体，不经过模拟转写确认页，也不产生演示任务的执行回执。Gateway 模式单独读取真实绑定和会话；尚无真实电量采集或设备间对讲。

Gateway 录音前通过 `request.prepare` 固定服务端目标，只在首次 prepare 成功后开启一轮录音。`listen.start` 携带本轮 `request_id`，平台将其逐轮透传到 MCP 的能力仍待验证。设备不上传 STT；OK 停录成功后登记确认意图，本轮原文到达后发送一次 `request.confirm`，不通过 `listen.detect/text_response` 或固定音频生成结果。灵矽 Agent 在原会话中调用 MCP、等待真实结果并自行回复。

结束按键被接受后立即冻结波形和读秒，显示停录／等待状态；本轮原语音连接收到播放结束并完成尾音收尾后返回概览。Gateway 状态只更新业务快照，不能制造成功声音或触发播放结束。用户取消时清理未执行请求；OK 已授权的本轮正常返回后保留确认意图，迟到原文继续使用同一请求。确认已进入发送队列后，错误、超时和重连只查询状态，不自动重投。服务端确认错误在请求状态页保留。

任务与历史仅保留少量显示项，不缓存识别原文及重复摘要；完整业务文字留在服务端。网络缓冲仍有容量和分配余量检查，展示在基础语音和网络之前退让；这不是预留了隔离内存，双 TLS 和 Opus 的真实峰值仍需真机测量。容量和验证步骤见[Gateway 接入说明](../docs/gateway-client.md)。

## 联网与录放音运行

`linx_device.c` 在独立工作任务中管理 Wi-Fi、网络时间、HTTPS 设备接入、WSS、Opus 解码及 BSP 音频。页面只投递有界命令，由主循环读取状态快照，网络与音频任务不持有界面对象。PREPARE 只准备到握手完成，START 才开启录音；同目标的预热可被后续请求接管。Wi-Fi 在正常操作后保持连接，录音期间暂停语音空闲期限，完整结束或取消后重新保留 30 秒；第 29 秒再次录入也从本条结束后重新计时。普通页面操作与心跳不续期。Gateway 按真实会话标识复用，独立模式按原演示上下文复用；目标变化或连接失效时重建。

CANCEL 发送 abort 并立即停止本地录放音，保留 WSS 静音排空旧轮；收到真实 tts.stop 才允许下一条录音。灵矽协议没有独立取消确认或每轮标识，不能把发送 abort 成功当作旧轮已结束；未结束时显示收尾状态，超时如实报错，不偷偷重连或重传。RELEASE 用于配网、替换后端和资源销毁的硬释放。正常播完只表示录放音结束，不表示 Codex 已接收。

Gateway 与灵矽的收发类型、状态、长度及结果会输出为 INFO 日志；原文与凭据不输出，音频不逐包打印。内存量测与日志含义见[串口协议日志](../docs/gateway-client.md#串口协议日志)。

“灵矽连接已断开”是统一传输失败提示。失败日志仅记录阶段、操作、返回值、帧类型／长度和 socket／TLS 数字错误码，关闭帧只取长度足够时的数字状态码；不记录语音、字幕、令牌、会话标识或关闭原因正文，SDK 握手日志保持静默。偶发等待／播放断开尚未复现，不能据新增诊断宣称已修复。

`linx_input_settings.*` 在独立任务中异步保存返回方式。启动时在 LVGL 锁外读取；没有值或值非法时默认长按，实际读取失败则报告。保存成功才切换当前手势并建立旧按键屏障；固定 SDK 的 set 会立即写入，报错不代表已回滚，重启后的偏好以真实读回为准。存储不擦除原有 NVS。

上行使用每 20 ms／640 字节的 16 kHz、16 bit、单声道 PCM，下行使用固定版本 `espressif/esp_audio_codec` 2.6.2 的 Opus 解码器，输出同一格式；最长 120 ms 包使用固定 3840 字节缓冲。缓冲不随对话时长增长；短流程已完成真机录音与回复验证并采样内存和栈水位，长期并行负载仍需板卡测量，详见[应用验收记录](#验收状态)。

保存网络时还需处理固定 SDK 的配置去重：试连成功后断开 STA 并排空旧事件，在 RAM 恢复本次配网前的配置，再切到 FLASH 写入新配置，以确保触发实际持久化。热点在这期间继续提供网页状态。回归须模拟同值写入被跳过，并验证重新初始化 Wi-Fi 后能读到已保存网络。

Wi-Fi 配网与语音共用同一个工作任务，扫描结果和命令使用固定容量。`linx_wifi_portal.*` 使用 ESP-IDF 自带 HTTP 服务提供手机网页，临时 WPA2 热点密码每次生成，配置只留 RAM，成功、取消或五分钟超时后关闭；HTTP 不与语音录放音同时运行。候选配置只在 RAM 试连，获得 IP 后才保存到 NVS，失败或取消保留旧配置；离开页面先停止网页服务和热点，再释放网络接口并清理扫描结果和密码缓冲。语音连接优先读取设备已保存网络，没有保存配置时才回退到 menuconfig 的开发配置。设备接入从 HTTPS 网关取得真实激活码或 WSS 鉴权信息；Token 只留在运行内存。HTTPS 和 WSS 保留证书及主机名验证，无法取得可用于校验的时间时报告失败。OTA 网关用于接入信息获取，本实现不执行固件更新。配置与操作见[固件说明](../README.md#灵矽配置与操作)。
