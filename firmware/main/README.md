# LinX 应用

本目录实现 LinX 0.2 应用：`main.c` 为设备入口，`linx_ui.*` 绘制界面，`linx_demo.*` 与 `linx_content.*` 管理任务和示例内容，`linx_input.*`、`linx_navigation.*`、`linx_reader.*` 分别处理按键、导航和分页阅读。`linx_voice.h` 定义语音与手机配网命令和状态，`linx_lingxi_protocol.*` 负责有界消息、设备接入与会话协议，其中 Hello、监听及打断规则从固定版本小智源码移植，来源和差异见 [`upstream.json`](../upstream.json)；`Kconfig.projbuild` 提供开关及 Wi-Fi 配置，`idf_component.yml` 固定解码器与现有 LVGL 版本。网络和录放音运行实现留在 [hardware/](../hardware/folotoy/ai-passport/README.md)，字体图片留在 [assets/](../README.md#资源与生成)。

## 操作与功能边界

- 上下键选择或翻页，OK 进入，长按 OK 约半秒返回；任务列表长按 OK 打开设备设置，关闭真实灵矽时仍为演示选项。
- 设备设置的“Wi-Fi 网络”打开手机配网，语音页提示先设置 Wi-Fi 时短按 OK 也可进入。设备显示临时热点和密码；手机连接后在 http://192.168.4.1 选择网络并输入密码，成功后自动保存并关闭热点。`linx_wifi.*` 只保留固定容量网络类型和密码格式检查；试连取得地址后才保存，失败可在网页重试，长按 OK 取消。
- 图片页按 OK 打开操作，正文页按 OK 进入语音页。默认启用真实灵矽对话：连接成功后开始录音，短按 OK 结束上传，播放回复后自动开始下一轮；播放时短按 OK 打断重录。下键或长按 OK 返回并取消。
- 未绑定时显示灵矽网关返回的真实六位激活码；在平台完成绑定后短按 OK 重试。连接、网络时间、协议或音频失败会显示状态，短按 OK 手动重试；不把上一轮录音自动重发。
- 关闭 `CONFIG_LINX_LINGXI_ENABLE` 后保留原模拟输入：八秒后或再按 OK 结束，再确认转写；离开确认页不会发送。
- 登录任务模拟运行八秒，支付任务等待回复，设计任务展示完整长回复和三张图片，每张包含两个固定局部。每个任务保留本次开机最近八轮，重启恢复初始示例。
- 演示选项可模拟离线或一次发送失败；未发送指令可恢复草稿后重试或取消。已接收指令离线时暂停，未收到的草稿需手动重试；每个任务只有一个待执行名额。

任务列表、回复正文、图片、电量和离线模式的转写仍为本地示例；真实模式的语音页直接连接灵矽智能体，不经过模拟转写确认页，也不产生演示任务的执行回执。当前没有真实 Codex 任务绑定、设备间对讲或真实电量采集。

真实语音页只显示已覆盖字形的静态状态与激活码，不展示任意 ASR／回复文本。`linx_voice.h` 的命令只投递给工作任务，页面按会话代号过滤迟到事件；网络回调不直接访问 LVGL。Wi-Fi 配置、固定缓冲和凭据边界见[固件配置说明](../README.md#灵矽配置与操作)。
