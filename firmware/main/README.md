# LinX 应用

本目录实现 LinX 0.2 离线界面演示：`main.c` 为设备入口，`linx_ui.*` 绘制界面，`linx_demo.*` 与 `linx_content.*` 管理任务和示例内容，`linx_input.*`、`linx_navigation.*`、`linx_reader.*` 分别处理按键、导航和分页阅读。调整页面、文案、交互或状态时修改这里；硬件接入留在 [hardware/](../hardware/folotoy/ai-passport/README.md)，字体图片留在 [assets/](../README.md#资源与生成)。

## 操作与功能边界

- 上下键选择或翻页，OK 进入，长按 OK 约半秒返回；任务列表长按 OK 打开演示选项。
- 图片页按 OK 打开操作，正文页按 OK 开始模拟输入；八秒后或再按 OK 结束，再确认转写。离开确认页不会发送。
- 登录任务模拟运行八秒，支付任务等待回复，设计任务展示完整长回复和三张图片，每张包含两个固定局部。每个任务保留本次开机最近八轮，重启恢复初始示例。
- 演示选项可模拟离线或一次发送失败；未发送指令可恢复草稿后重试或取消。已接收指令离线时暂停，未收到的草稿需手动重试；每个任务只有一个待执行名额。

任务、回复、图片、连接、电量与语音转写均为本地示例。应用不启动无线、录音、扬声器或真实电池参数初始化，尚未实现对讲。

## 验收状态

构建和主机截图不能证明真机通过。仍需检查真实配色、中文、圆角、实体键短按／长按及返回路径。三十分钟稳定性测试由用户暂停，不自动恢复；长期稳定性继续记为未验证。真机报告须保留准确镜像哈希与匹配的 ELF，记录堆内存和任务栈水位。
