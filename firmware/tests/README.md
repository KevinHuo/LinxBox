# 自有测试

`test_linx_demo.c`、`test_linx_input.c`、`test_linx_navigation.c`、`test_linx_reader.c` 检查应用状态、按键、导航和阅读逻辑；按键回归覆盖默认长按返回、长按松手不确认、双击模式延迟单击和完整双击、切换模式与切页后旧手势失效；`test_prepare_upstream.py`、`test_check_repo.py`、`test_check_c_coverage.py` 检查依赖准备、本地门禁及覆盖率门槛。

`test_linx_wifi.c` 检查密码长度和格式边界；`test_linx_wifi_portal.c` 检查手机网页、HTTP 参数、状态和有界凭据传递。设备运行测试还模拟 Wi-Fi 扫描、临时热点、取消、同一网页多次 RAM 试连及成功后保存，确认错误密码不会覆盖旧网络；真实 LVGL 测试覆盖手机配网指引、热点凭据校验与清理、错误重试及回到原语音页。这些测试不替代实际路由器与设备配网验证。

`test_main_runtime.c` 运行真实 `main/main.c` 和上游按键保护逻辑，`device_stubs/` 仅提供 ESP-IDF／BSP 接口替身。每个场景在独立进程中调用一次设备入口，模拟初始化失败、唤醒保护、队列溢出、切页屏障和定期内存日志，检查调用顺序及结果；这部分不连接板卡，也不能证明真实驱动行为。

`test_linx_protocol.c` 使用 ESP-IDF 中的真实 cJSON，检查设备接入消息、激活码、WSS 地址、会话事件、长度上限及 WebSocket 拆包，并回归小智最小 Hello、可选音频参数和开始／停止／打断消息；`test_linx_device.c` 运行本地 `main/linx_device.c`，通过 `sdk_stubs/` 模拟 Wi-Fi、时间、HTTPS、WebSocket、Opus 与 BSP 接口。后台 PREPARE 只到握手就绪，不初始化或读取音频；START 才开启一条录音，播完尾音并关闭音频后发布 FINISHED，保留同目标通道与 STA。覆盖 30 秒空闲期限、心跳不续期、上下文逐字段变化、缓存失效、预热途中启动、代号交接、取消后立即准备、提前回复、重复开始、中止回复、尾音取消／断网以及配网资源移交。新一条录音必须显式 START，不自动重传；测试结束时才通过替身明确释放常驻资源，不把测试收尾当作产品每轮断网。替身不访问真实灵矽、网络、麦克风或账号，不能证明 Opus 库的真实解码效果、Codex 送达、实际延迟或真机语音链路。

连接生命周期回归额外检查第 29 秒开始下一条、对话跨越旧期限、结束后重新保留完整 30 秒，并直接断言网关与 WSS 建立次数。同目标预热中的退出、重进和 START 不打断握手。CANCEL 与 RELEASE 分别覆盖软取消和硬释放：软取消不提交 listen.stop，立即停止本地录放音并保留连接，旧轮数据静音丢弃，真实 tts.stop 后才允许下一条；没有结束、等待中再退出、快照覆盖或迟到事件都不能误开麦。真实服务端是否及时结束已取消的录音仍需分别验证。

断线诊断回归在等待与播放阶段注入轮询、读取、发送和关闭帧故障，检查阶段及数字错误信息，并断言日志不包含私密正文或鉴权信息、失败后不自动重录或重发。这些替身故障不代表已复现真机偶发断开，真实原因仍须结合故障瞬间日志确认。

冷启动校时回归模拟最多 5 秒启动延迟、首台服务器无应答后 15 秒轮换，覆盖超过原 10 秒期限才成功、三个时间源分别成功、全部失败后 60 秒退出、等待期间取消与断网，以及已有有效时间时跳过校时。测试只验证应用能正确等待 SDK，不代替真实 DNS、UDP、备用服务器切换和断电重启验证。

`linx_host/` 在电脑上运行同一套应用界面与真实 LVGL，使用 240 × 320 虚拟屏幕自动执行按键、检查集成行为并保存截图。首版回归检查三个任务的概览只有三项、历史不显示图片附件、文字阅读每页单击 OK 无操作、使用配置手势返回后从“继续沟通”录入，重新打开文字保留原页码；包含离线演示与真实语音后端替身两种模式。后台准备与前台录音分别记录请求，同时保留完整请求顺序，检查概览只准备一次、阅读不录音、目标更新重新准备、录音使用独立代号、后台状态不抢焦点及后端替换／配网／清理所有权。正常 FINISHED 不发送 CANCEL，恢复概览后只追加后台准备。交互回归覆盖两种方式的根页设置、其他页返回、语音页上下键不取消、返回直接软取消且不触发结束上传或发送，以及配网页退出清理。单条指令回归检查等待／播放期间 OK 不重录，正常结束后回到概览并保留选项，状态快照跳过播放状态仍能返回，提前／错误／重复／旧代号结束事件无效，且不产生模拟发送回执。失败重试、离线保留、排队、后台完成、历史淘汰与生命周期场景均从文字入口执行；图片浏览专属场景和缺图测试目标随功能移除。`lv_conf.h` 配置图形库，`CMakeLists.txt` 声明电脑上的构建，`test_main_contract.py` 检查设备入口的按键与页面处理顺序。

`linx_host/test_ui_boundaries.c` 直接包含真实界面实现，单独测试内部对象容量、文字测量及导航边界，断言容量用尽后不会越界并可重置复用；不为测试增加业务 API。

在线字体回归把实际远程汉字逐像素与既有 UI 粗体比较，检查灰度边缘及笔画覆盖，防止退回细体或黑白二值字形。列表、概览、正文和录音页继续通过真实 LVGL 截图与字形／布局审计；主机与固件必须同时启用大字库偏移，构建另检查镜像能放入现有应用分区。

工程归属回归覆盖不同工程的同名任务、长工程名与最长状态同时展示、历史页工程名、详情尚未加载、连接错误及会话切换，避免把旧工程标到其他会话上。列表沿用两行布局及现有对象池。

在固件根目录运行 `./tools/validate_linx_host.sh`，默认结果位于 `build/linx-host/`。这是自动测试与截图方式；先核对画面差异，再决定是否更新基线，不自动接受截图变化。屏幕实际配色和实体键仍需真机检查。

行为、边界或缺陷发生变化时更新相关测试，激活 ESP-IDF 5.5.3 后在固件根目录运行 `./tools/validate.sh --static`；静态检查中的协议测试需要 IDF 自带的真实 cJSON 源码。上游原有测试直接从固定依赖运行，不在这里复制；主机通过不能替代真机验收。

`./tools/validate_coverage.sh` 会重新构建并运行以上 C 测试，统一统计 `main/` 与 `hardware/` 内全部自有 C 源码（包括设备入口和灵矽设备运行实现）的行、分支和函数覆盖率；整体及每个文件三项均要求至少 90%。第三方 BSP／LVGL／cJSON／音频解码库、生成资源和测试替身不计入应用指标，新增自有源码若未进入报告会直接失败。环境、报告位置见[工具说明](../tools/README.md)。

`test_linx_input_settings.c` 核对默认值、异步保存、关闭运行对象后的重启读回、非法值、读取／队列／任务失败及资源清理。替身按固定 ESP-IDF 的 set 即写入行为模拟，覆盖写入后报错与提交失败，不将关闭句柄当成回滚。UI 测试另外核对保存成功后才切换、失败保持当前模式、离页结果不跳转，以及保存确认重绘期间排队的旧按键不能穿透新模式。


Gateway 回归使用正式共享 Schema，验证目录、历史、正文、推送刷新、固定目标 prepare、单轮录音许可和重连恢复。设备不发送 `request.propose` 或列表 `limit`，也不生成指定播报；OK 停录被接受后才授权 `request.confirm`，覆盖原文先到／后到、重复按键、取消和断线后只读恢复。`test_gateway_socket.mjs` 通过 TLS mock 驱动真实 C/LVGL 界面；`test_go_gateway.mjs` 另启动正式 Go Gateway，以模拟 Desktop 提供查询数据、模拟灵矽来源头调用真实 SSE MCP，确认原文落盘、单次确认和 UI 刷新。后者明确断言当前服务返回调度未实现、错误保留且没有任务投递，不能把草稿保存当成“已发送”。测试不连接私人账号，不调用真实 Codex。

从固件目录运行 `./tools/validate_gateway_mock.sh` 和 `./tools/validate_go_gateway.sh`。第二项需要仓库 Go 工具链，仍须单独验证真实灵矽平台的逐轮请求头透传、工具路由和部署后的任务投递。
